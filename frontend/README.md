# HRMS

React + TypeScript + Vite frontend prototype. Run `npm install`, `npm run dev`, `npm run build`, and `npm test` from this directory.

The demo toolbar selects role and employee identity. Data persists in this browser. Settings provides JSON backup, restore and demo reset.

See [prototype coverage](../docs/HRMS_PROTOTYPE.md) and [HRMS feature backlog](../docs/HRMS_FEATURES.md).
